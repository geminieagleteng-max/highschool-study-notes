### 三、幾何方程式的本質與角平分線條件推導

**老師**：所有人抬頭看我，圖畫完了嗎？

請先告訴我：角平分線在哪裡？我有兩種顏色，用黃色跟紅色。這兩條白色線的角平分線在哪裡？是不是有一條在這邊？它會把這個角平分，所以畫上記號（圈圈）。

大家現在就要跟著畫，等一下就要把講義蓋起來了。沒有畫錯位置吧？

第二條應該大家可以自己畫上去了，另外一條應該在這邊，記號換成叉叉。

在名稱上面，各位應該會發現：黃色線平分的是什麼角呢？**銳角**；紅色線平分的是什麼角呢？**鈍角**。所以我們給它一個名稱：黃色線寫上「**銳平**」（銳角平分線），紅色線寫上「**鈍平**」（鈍角平分線）。

如果大家都跟上了，幫我把講義全部蓋起來！不能作弊哦，等一下我講完之後全班要自己手寫一次。我之後一定會考這題，這是一年後第二次段考最受歡迎的手寫非選擇題。手寫題有一個地方沒寫好，觀念分數就會一直被扣，所以我們現在來測驗一次，課本蓋起來！

專心看我。各位，我們現在來講這個角平分線。

我們已經講了三四堂課的幾何了，你現在對於幾何圖形，還有我幫你架構好的框架嗎？重新來一次：**什麼是幾何方程式？**

一般同學以為幾何方程式是圖形的「名稱」，但你已經了解了，它不是名稱，它是這個圖形的**來源**。所謂的幾何方程式，指的是**圖形上每一個點代入都會符合的 \\((x, y)\\) 座標關係式**。

我今天要求的這條線——譬如我要求黃色線或是紅色線——我其實是想知道這條線上每一個點的 \\(x\\) 與 \\(y\\) 座標所具有的關係式。這個關係在黃色線上無窮多的點、以及紅色線上無窮多的點上均滿足。

那麼這個關係式是什麼呢？

首先，我先假設有一個不斷移動的動點叫做 \\(P(x, y)\\)。這個點在黃色線上跑來跑去、在紅色線上跑來跑去，所以它屬於角平分線。

角平分線上的任何一個點，有什麼幾何特色？這是今天上課一開始討論的：**角平分線上的點到達兩個邊（兩直線）的垂直距離會是一樣的**。

我們把兩條白色直線設為 \\(L_1\\) 與 \\(L_2\\)，那麼 \\(P\\) 到達 \\(L_1\\) 的距離與到達 \\(L_2\\) 的距離應該要相等：
\\[ d(P, L_1) = d(P, L_2) \\]

我的學生，你在高中三年裡面，只要遇到角平分線的問題，只要記得這句話就可以了！

旁邊同學可能會想：「這太突然了吧？我知道角平分線上的點到兩邊距離相等啊，然後呢？這樣就表示寫出方程式了嗎？」

我還沒寫完，但我已經快要完成了。角平分線上的每個人到達兩直線距離相等；這句話反過來說也是對的——**只要點到兩直線的距離相等，就一定會落在角平分線上**。所以符合這個條件的 \\(P\\) 點，一定會在角平分線上。

你考試手寫題一定要幫我寫出 \\(d(P, L_1) = d(P, L_2)\\) 這個幾何條件，只要寫出這個，剩下計算都算我的責任！

### 四、代數計算：絕對值拆解與方程式求解

**老師**：接下來，\\(P(x, y)\\) 到達 \\(L_1\\) 的距離跟到 \\(L_2\\) 的距離要怎麼寫呢？

利用點到直線距離公式：
* 到 \\(L_1\\)（\\(2x + 3y - 1 = 0\\)）的距離：
  \\[ \frac{|2x + 3y - 1|}{\sqrt{2^2 + 3^2}} \\]
* 到 \\(L_2\\)（\\(3x + 2y + 3 = 0\\)）的距離：
  \\[ \frac{|3x + 2y + 3|}{\sqrt{3^2 + 2^2}} \\]

兩邊列出等式：
\\[ \frac{|2x + 3y - 1|}{\sqrt{13}} = \frac{|3x + 2y + 3|}{\sqrt{13}} \\]

這時候，兩邊分母都是 \\(\sqrt{13}\\)，可以直接約分消掉！消掉後形成兩側都有絕對值的型態：
\\[ |2x + 3y - 1| = |3x + 2y + 3| \\]

如果兩個人取絕對值之後相等，代表兩個人是什麼關係？要麼同號，要麼異號！如果取絕對值後是 \\(3\\)，原本可能就是 \\(+3\\) 或 \\(-3\\)。

為了解開這個式子，最棒的做法就是：**左邊直接拆開，右邊加上正負號**（同號與異號）。

（**口訣記憶**：如果一隻「熊」跟一隻「貓」絕對值之後相等，即 \\(|\text{熊}| = |\text{貓}|\\)，拆開絕對值就是：\\(\text{熊} = \pm \text{貓}\\)。）

現在我們來拆解：

1. **第一種情況（取正號）**：
   \\[ 2x + 3y - 1 = +(3x + 2y + 3) \\]
   移項整理：
   \\[ 3x - 2x + 2y - 3y + 3 + 1 = 0 \implies x - y + 4 = 0 \\]
   這樣就算出第一條線了！

2. **第二種情況（取負號）**：
   \\[ 2x + 3y - 1 = -(3x + 2y + 3) \\]
   展開右邊：
   \\[ 2x + 3y - 1 = -3x - 2y - 3 \\]
   移項整理：
   \\[ 5x + 5y + 2 = 0 \\]
   第二條線也算出來了！

這本題就算完了！只要記得幾何條件，寫出公式、絕對值拆開整理，答案就出來了。

### 五、斜率判定與銳角/鈍角平分線對照

**老師**：最後，我要跟你講一件最關鍵的事。

為什麼這個題目我堅持要你「大略精準作圖」，形狀一定要畫對？為什麼？

因為求出來的兩條角平分線，一條是銳角平分線（銳平），一條是鈍角平分線（鈍平）。由我們剛剛畫的圖可以觀察到：**銳平的斜率是負的，鈍平的斜率是正的**。這樣你才可以正確區分題目到底要的是哪一個！

我們一起檢查算出來的這兩條線：
* 第一條線 \\(x - y + 4 = 0\\)：
  斜率 \\(m = -\frac{a}{b} = -\frac{1}{-1} = 1\\)（正斜率）。
  對照圖形，這條斜率為正的直線就是**鈍角平分線（鈍平）**。

* 第二條線 \\(5x + 5y + 2 = 0\\)：
  斜率 \\(m = -\frac{a}{b} = -\frac{5}{5} = -1\\)（負斜率）。
  對照圖形，這條斜率為負的直線就是**銳角平分線（銳平）**。

這樣講可以理解嗎？
