## 課堂開場與絕對值不等式題型解析（第 5 題與基本類題）

**老師**：第五題幫我打十顆星，打十顆星。好，我先問一下，第五題寫對的舉手？一、二、三、四、五，OK，有五個同學寫對，很不賴喔！那不管你寫錯還是寫對，都要陪我一起看一下。這題有點太難了，所以我們 ELECTRICAL 先幫大家做一些簡單的基礎動作。例如說你在考試看到這個題目，可能會覺得不太知道怎麼著手，你可以先想一下是哪裡卡住。很明顯就是這個「3」特別機車。所以我們宣先來寫一個簡單的版本，請幫我在空白的地方先寫一個簡單的類題。大多數學校考的是這種比較簡單的格式，我們來寫一下這個類題。

如果今天題目講的是：

\\[|x - 30| < |x - 50| < |x + 30|\\]

如果題目是這樣子的話，我們先把係數「3」擺一邊，那個 3 確實有點討厭。這樣我們就可以回到國中數學的概念來思考。我會用兩種顏色，大家可以學習一下這個思路。

第一個概念：「我比你小，你又比他小」，這句話其實包含兩句話：第一個是我小於你，第二個是你小於他。我們拆成兩半來處理，先解左半邊：

\\[|x - 30| < |x - 50|\\]

**老師**：這裡用國中的概念就可以了：在數線上，\\(x\\) 到 \\(30\\) 的距離，小於 \\(x\\) 到 \\(50\\) 的距離。我們在數線上標出 \\(30\\) 與 \\(50\\)。高手在看不等式的時候，會先去思考「等於」的狀況。當等於成立時，表示到 \\(30\\) 的距離與到 \\(50\\) 的距離是一樣的，那個位置會在 \\(30\\) 與 \\(50\\) 的正中間，也就是 \\(40\\)。但題目講的是「小於」，意思是到 \\(30\\) 的距離比較小，也就是離 \\(30\\) 比較近，所以 \\(x\\) 應該要在 \\(40\\) 的左手邊。當兩邊距離一樣時是 \\(40\\)，要離 \\(30\\) 比較近，第一個部分就可以得到解答：

\\[x < 40\\]

接著看第二個部分：

\\[|x - 50| < |x + 30|\\]

注意 \\(|x + 30|\\) 可以看成 \\(x\\) 到 \\(-30\\) 的距離。我們標出 \\(50\\) 與 \\(-30\\)。高手看不等式先想等式，如果這裡是等號，表示到 \\(50\\) 與到 \\(-30\\) 的距離相同，正中間位置是 \\(10\\)。題目要求到 \\(50\\) 的距離比較近，所以應該要從 \\(10\\) 開始向右延伸。因此第二部分得到：

\\[x > 10\\]

把這兩句話合併在一起看，答案就會是介於 \\(10\\) 到 \\(40\\) 之間：

\\[10 < x < 40\\]

下方的類題是用國中幾何解法處理，如果你想用幾何解法，必須先對這種基本題型有概念，否則上面的第五題很難突然想到。

## 絕對值不等式的雙重解法：幾何距離分點法與高中代數區間討論法

**老師**：現在我們要來征服上面原本的第五題。同樣地，我們分成分段來討論。

第一句話是：

\\[|x - 30| < 3|x - 50|\\]

這句話的意思是：我到 \\(30\\) 的距離，小於我到 \\(50\\) 的距離的三倍。高手看到這種式子，會先思考等式成立的情況：

\\[|x - 30| = 3|x - 50|\\]

這可以寫成國中學過的比例關係，即到 \\(30\\) 的距離與到 \\(50\\) 的距離之比為 \\(3 : 1\\)：

\\[|x - 30| : |x - 50| = 3 : 1\\]

我們在數線上標出 \\(30\\) 與 \\(50\\)。內分點的位置在 \\(30\\) 與 \\(50\\) 之間，按 \\(3 : 1\\) 切割。兩點長度差距為 \\(20\\)，分成四等份，每等份是 \\(5\\)，所以內分點位置是：

\\[x = 45\\]

除了內分點，還有可能是外分點。如果到 \\(30\\) 的距離比較遠，在 \\(50\\) 的右側也會有一個 \\(3 : 1\\) 的外分點結構。長度 \\(20\\) 對應到兩等份（\\(3 - 1 = 2\\)），每等份是 \\(10\\)，從 \\(50\\) 再向右加 \\(10\\)，外分點位置就是：

\\[x = 60\\]

當等號成立時，會有兩個邊界點：\\(x = 45\\) 或 \\(x = 60\\)。

接著判定不等式方向：如果要求 \\(|x - 30| < 3|x - 50|\\)，從 \\(45\\) 這個點來看，如果要讓到 \\(30\\) 的距離小於到 \\(50\\) 距離的三倍，點必須向左走，所以第一個區間解答是：

\\[x < 45\\]

對於外分點 \\(60\\)，如果向右走，雖然到兩點的距離都增加了一小段，但到 \\(50\\) 的距離增加的這一小段乘以三倍之後變大得更多，反而會使左邊式子相對較小，所以點必須向右走，第二個區間解答是：

\\[x > 60\\]

因此第一部分得到的解為 \\(x < 45\\) 或 \\(x > 60\\)。

第二句話是：

\\[3|x - 50| < |x + 30|\\]

同樣先想等式：\\(|x - 50| : |x + 30| = 1 : 3\\)。
標出 \\(50\\) 與 \\(-30\\)，內分點按 \\(1 : 3\\) 切割得 \\(x = 30\\)；外分點按 \\(1 : 3\\) 在右側切割得 \\(x = 90\\)。
經由方向判定，解會介於 \\(30\\) 與 \\(90\\) 之間：

\\[30 < x < 90\\]

最後將兩部分的結果進行綜合取交集：
- 第一部分：\\(x < 45\\) 或 \\(x > 60\\)
- 第二部分：\\(30 < x < 90\\)

交集區間為 \\(30 < x < 45\\) 以及 \\(60 < x < 90\\)。兩段長度分別為 \\(15\\) 與 \\(30\\)，總長度為 \\(45\\)。

**老師**：這是國中的幾何思考解法，思考要非常冷靜。現在我們來看高中生的標準做法：代數區間討論法。

高中的解法原則是：「誰有絕對值就討論誰！」因為討論的目的是為了拆掉絕對值符號，如果本來就沒有絕對值，就不需要去討論它。

以 \\(|x - 30| < 3|x - 50|\\) 為例，令內部為零的分界點分別為 \\(30\\) 與 \\(50\\)，將數線切分成三個片段：
1. 當 \\(x \ge 50\\) 時：兩式拆開皆為正，拆去絕對值直接計算得 \\(x > 60\\)。與前提 \\(x \ge 50\\) 取交集得 \\(x > 60\\)。
2. 當 \\(30 \le x < 50\\) 時：前正後負，後式加負號，計算得 \\(x < 45\\)。與前提取交集得 \\(30 \le x < 45\\)。
3. 當 \\(x < 30\\) 時：兩式皆為負，皆加負號，計算得 \\(x < 60\\)。與前提取交集得 \\(x < 30\\)。

最後把第二與第三區間合併，包含 \\(30\\) 本身且小於 \\(30\\)，直接聯集可寫成 \\(x < 45\\)。結合第一區間，最終解答為 \\(x < 45\\) 或 \\(x > 60\\)。這與幾何法求出的結果完全相同。

## 三角不等式定理與雙絕對值極值速解

**老師**：請大家在第 11 頁右下角補充一個重要觀念：三角不等式。

任意兩個實數，先取絕對值再相加，與先相加再取絕對值相比：

\\[|a| + |b| \ge |a + b|\\]

左邊一定會大於等於右邊。這是因為先取絕對值後兩數皆為正，相加時完全不會互相抵消；而右邊若是先相加，若是一正一負就會產生抵消，導致取絕對值後數值變小。

我們來分析兩種情況：
1. **嚴格大於（\\(|a| + |b| > |a + b|\\)）**：當 \\(a, b\\) 異號（即 \\(ab < 0\\)）時，先相加會互相抵消，導致右式較小。
2. **等號成立（\\(|a| + |b| = |a + b|\\)）**：當 \\(a, b\\) 同號或有人為 \\(0\\)（即 \\(ab \ge 0\\)）時，兩數不抵消，等號成立。

**課堂互動**：看第 33 題第 (1) 小題，題目給定 \\(|a| + |b| \ge |a + b|\\)，請問等號成立的條件是什麼？

**老師**：等號成立條件就是 \\(a, b\\) 同號或有零，在高中數學的代數表達式中寫作：

\\[ab \ge 0\\]

若為異號則寫作 \\(ab < 0\\)。

三角不等式最大的實用功能，是在求解「雙絕對值相加的最小值」問題時，作為一種極快的速解法。

以第 33 題第 (2) 小題為例：求 \\(f(x) = |x + 1| + |x - 3|\\) 的最小值。

**老師**：因為絕對值內部加負號不影響結果，即 \\(|x - 3| = |-x + 3|\\)。我們把原式改寫為：

\\[f(x) = |x + 1| + |-x + 3|\\]

利用三角不等式：

\\[|x + 1| + |-x + 3| \ge |(x + 1) + (-x + 3)| = |4| = 4\\]

變數 \\(x\\) 與 \\(-x\\) 精準抵消，直接得出最小值為 \\(4\\)。

## 三角不等式等號成立條件與解的存在性討論

**老師**：回到剛才的題型，我們來看剛才求出最小值的等號成立條件。

剛才使用三角不等式的是 \\(x + 1\\) 與 \\(-x + 3\\) 這兩項。等號成立條件是這兩項同號或有零，即：

\\[(x + 1)(-x + 3) \ge 0\\]

兩邊同乘以 \\(-1\\) 並改變不等號方向：

\\[(x + 1)(x - 3) \le 0\\]

解這個二次不等式，可得 \\(x\\) 介於兩根之間：

\\[-1 \le x \le 3\\]

這表示當 \\(x\\) 介於 \\(-1\\) 到 \\(3\\) 之間時，\\(f(x) = |x + 1| + |x - 3|\\) 均可達到最小值 \\(4\\)。

看第 33 題第 (3) 小題：若不等式 \\(|x + 1| + |x - a| < k\\) 無解，求 \\(k\\) 的範圍。

**老師**：這句話翻譯成白話文意思是：左邊這串絕對值相加的結果，絕對不可能小於 \\(k\\)。
既然不可能小於 \\(k\\)，表示左邊的最小值必須大於等於 \\(k\\)。

我們用剛才的速解法求左邊的最小值：

\\[|x + 1| + |-x + a| \ge |(x + 1) + (-x + a)| = |a + 1|\\]

因此最小值為 \\(|a + 1|\\)。要使不等式無解，\\(k\\) 必須小於或等於這個最小值：

\\[k \le |a + 1|\\]

## 超級等式觀念與老師個人經驗分享

**老師**：大家請回座位，看黑板。我們來看北一女的這道考題。

題目第一題：設 \\(a, b, c, d\\) 為實數，若 \\(a + b\pi = c + d\pi\\)，則 \\(a = c\\) 且 \\(b = d\\)。這個敘述是錯誤的。

錯誤的原因在於題目給定的條件是「實數」。\\(\pi\\) 是無理數，如果要有理部等於有理部、無理部等於無理部（即 \\(a = c\\) 且 \\(b = d\\)），前提條件必須是 \\(a, b, c, d\\) 皆為「有理數」。

我們暑假時把這個性質稱為「超級等式」。如果沒有限定 \\(a, b, c, d\\) 為有理數，我們隨便舉個反例，例如取 \\(b = 0, d = 1, a = 3 + \pi, c = 3\\)，等式 \\(a + b\pi = c + d\pi\\) 依然成立，但 \\(a \ne c\\) 且 \\(b \ne d\\)。

這提醒我們：題目沒寫「有理數」三個字，千萬不能直接對照係數！

**老師**：上課大家要保持專注。講到這個，我最近剛辦完結婚登記。結婚這件事讓我有一些體會。

## 超級等式手寫大題反證法嚴密證明 SOP

**老師**：如果段考手寫題出了一道 10 分的大題，要你證明超級等式：

> 若 \\(a, b, c, d \in \mathbb{Q}\\) 且 \\(\sqrt{2} \notin \mathbb{Q}\\)，若 \\(a + b\sqrt{2} = c + d\sqrt{2}\\)，求證 \\(a = c\\) 且 \\(b = d\\)。

大家知道該怎麼嚴密書寫證明嗎？標準方法是使用「反證法」。手寫 SOP 如下：

**第一步：假設反面**
假設 \\(b \ne d\\)。

**第二步：移項與代數推導**
將原式 \\(a + b\sqrt{2} = c + d\sqrt{2}\\) 進行移項：

\\[b\sqrt{2} - d\sqrt{2} = c - a \implies (b - d)\sqrt{2} = c - a\\]

因為假設 \\(b \ne d\\)，故兩邊同除以 \\((b - d)\\)：

\\[\sqrt{2} = \frac{c - a}{b - d}\\]

**第三步：指出矛盾**
因為 \\(a, b, c, d \in \mathbb{Q}\\) 且 \\(b - d \ne 0\\)，所以右式 \\(\frac{c - a}{b - d}\\) 必為有理數。
然而左式 \\(\sqrt{2}\\) 已知為無理數。「無理數等於有理數」產生嚴重矛盾！

**第四步：宣告結論**
矛盾說明原假設 \\(b \ne d\\) 錯誤，故 \\(b = d\\)。
將 \\(b = d\\) 代回原式可得 \\(a = c\\)。得證。

## 實數系架構、循環小數轉換與高位數求解（第 6 題）

**老師**：我們繼續複習實數系。有理數（\\(\mathbb{Q}\\)）包含三個分支：
1. 整數
2. 有限小數
3. 無限循環小數

循環小數轉換成分數的口訣：「**有帽念 9，無帽念 0，由後往前念**」。

例如將 \\(0.52\bar{3}\\) 化為分數：分母由後往前看，一個帽子念 9，兩個無帽子念 0，分母為 \\(900\\)（註：若為 \\(0.5\bar{23}\\) 則分母為 \\(990\\)）。分子為全數字 \\(523\\) 扣掉無帽子的部分 \\(52\\)：

\\[0.5\bar{23} = \frac{523 - 5}{990}\\]

看牛皮紙講義第 6 題（打十顆星）：求 \\(\frac{16241}{49950}\\) 小數點後第 \\(51\\) 位數字。

大家不可能真的拿筆去硬除。我們觀察分母 \\(49950\\)，分子分母同乘以 \\(2\\)：

\\[\frac{16241 \times 2}{49950 \times 2} = \frac{32482}{99900}\\]

分母 \\(99900\\) 代表這個小數的格式為 \\(0.ab\overline{cde}\\)，其轉換公式為：

\\[\frac{abcde - ab}{99900} = \frac{32482}{99900}\\]

逆推分子 \\(abcde\\)：

\\[abcde - ab = 32482 \implies abcde = 32482 + 32 = 32514\\]

所以這個小數為 \\(0.32\overline{514}\\)。
小數點後前兩位（\\(3, 2\\)）不參與循環，循環節為 \\(5, 1, 4\\)，長度為 \\(3\\)。
要求第 \\(51\\) 位數字，先扣除前兩位非循環數字：

\\[51 - 2 = 49\\]

計算循環位置：

\\[49 \div 3 = 16 \dots 1\\]

餘數為 \\(1\\)，代表是循環節 \\(5, 1, 4\\) 中的第 \\(1\\) 個數字，答案就是 **5**。

## 有限小數判定條件與經典歷屆試題解析

**老師**：有限小數的判定定理：一個最簡分數能化為有限小數，**約分後分母的質因數只能含有 2 或 5**。

我們來看一道經典考題：

> 設 \\(A\\) 為正整數，若 \\(\frac{A}{21}\\) 介於 \\(1\\) 與 \\(3\\) 之間，且 \\(\frac{A}{21}\\) 可化為有限小數，求 \\(A\\) 的可能值。

列出不等式：

\\[1 < \frac{A}{21} < 3 \implies 21 < A < 63\\]

分母 \\(21 = 3 \times 7\\)。要讓 \\(\frac{A}{21}\\) 約分後成為有限小數，分子 \\(A\\) 必須提供因數 \\(3\\) 或 \\(7\\) 來約去分母中的 \\(3\\) 或 \\(7\\)，使得剩餘的分母質因數僅包含 \\(2\\) 或 \\(5\\)。

我們逐一檢視 \\(A \in (21, 63)\\) 的範圍，將能與 \\(21\\) 完全約分且分母僅剩 \\(2, 5\\) 次方的 \\(A\\) 值圈選出來，即可得出所有解。

## 實數觀念多選題與無理數尺規作圖

**老師**：我們來看多選題概念：

1. **選項 (1)**：若 \\(a + b\pi = c + d\pi\\)，則 \\(a = c, b = d\\)。錯誤，因為未註明 \\(a, b, c, d\\) 為有理數。
2. **選項 (2)**：任意兩個不相等的有理數與無理數之間，至少存在一個無理數。正確，實數具有稠密性，兩數之間存在無數個無理數。
3. **選項 (3)**：若 \\(3a + b \in \mathbb{Q}\\) 且 \\(a - 2b \in \mathbb{Q}\\)，則 \\(a \in \mathbb{Q}\\)。正確，將兩式聯立消去 \\(b\\)：\\(2(3a + b) + (a - 2b) = 7a\\)。因為有理數經由加減乘除（除數不為零）後仍為有理數，故 \\(a\\) 必為有理數。

**老師**：回顧無理數的尺規作圖方法（半圓與幾何平均定理）：
要作出 \\(\sqrt{12} = \sqrt{3 \times 4}\\)：
1. 在直線上連續取長度為 \\(3\\) 與 \\(4\\) 的兩線段。

3. 從長度 \\(3\\) 與 \\(4\\) 的交界點作垂直於直徑的線段交半圓於上一點，此垂直線段的長度即為 \\(\sqrt{3 \times 4} = \sqrt{12}\\)。

## 多變數極值評估與強迫分解法、配方法

**老師**：我們看北一女多選題第二題：已知 \\(-1 \le x \le 3\\)，\\(2 \le y \le 5\\)。

**評估 \\(x^2 y\\) 的範圍**：
先算 \\(x^2\\) 的範圍：當 \\(-1 \le x \le 3\\) 時，\\(x^2\\) 的最大值為 \\(3^2 = 9\\)，最小值為 \\(0^2 = 0\\)（因為經過 \\(0\\)），故 \\(0 \le x^2 \le 9\\)。
再與 \\(2 \le y \le 5\\) 交叉測試端點候選人：\\(9 \times 5 = 45\\)，\\(9 \times 2 = 18\\)，\\(0 \times 5 = 0\\)，\\(0 \times 2 = 0\\)。
故 \\(0 \le x^2 y \le 45\\)。

**評估 \\(xy - x + y + 7\\) 的極值**：
因為同一個 \\(x\\) 與 \\(y\\) 出現在不同項中，不能拆開各自取最大值。我們必須進行「強迫分解」來集中變數：

\\[xy - x + y + 7 = (x + 1)(y - 1) + 8\\]

計算範圍：
- 因為 \\(-1 \le x \le 3 \implies 0 \le x + 1 \le 4\\)
- 因為 \\(2 \le y \le 5 \implies 1 \le y - 1 \le 4\\)

相乘範圍：

\\[0 \le (x + 1)(y - 1) \le 16\\]

全式加上 \\(8\\)：

\\[8 \le (x + 1)(y - 1) + 8 \le 24\\]

注意：若原本不等式條件沒有包含等號，端點值無法實際達到，就不能稱該端點值為「最小值」。

**單變數二次式配方法**：
例如求 \\(x^2 - 2x + 3\\) 在 \\(-1 \le x \le 3\\) 的範圍：
配方得 \\((x - 1)^2 + 2\\)。
因為 \\(-1 \le x \le 3 \implies -2 \le x - 1 \le 2 \implies 0 \le (x - 1)^2 \le 4\\)。
加上 \\(2\\) 得範圍為 \\(2 \le (x - 1)^2 + 2 \le 6\\)。
