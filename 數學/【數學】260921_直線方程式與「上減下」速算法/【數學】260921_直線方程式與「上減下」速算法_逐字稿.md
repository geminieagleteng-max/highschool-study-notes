## 📖 課堂講授：直線方程式與「上減下」萬能速算法

**老師**：重新整理一下，如果你願意把斜率寫成一個分式，那你就可以做到一步驟寫成標準直線方程式的格式。如果我們把斜率寫成 \\(\frac{A}{B}\\)，並且通過一個點 \\((s, t)\\)。按照剛才點斜式的關係，我們寫成：

\\[ y - t = \frac{A}{B}(x - s) \\]

把分母 \\(B\\) 乘過來得到 \\(B(y - t) = A(x - s)\\)，展開後移項整理：

\\[ Ax - By = As - Bt \\]

所以我們發現，只要把斜率寫成 \\(\frac{A}{B}\\)，就可以用分式的上面 \\(A\\) 減去下面 \\(B\\)，寫成 \\(Ax - By\\)。右邊的常數項不重要，因為左邊寫好之後，直接把已知點帶進去就能求出常數。這就是所謂的「萬能寫法」。

請大家在鉛筆盒裡拿最特別顏色的筆劃記這三個字：「**上減下**」。上減下就是最快能寫出直線關係式的方法。

我們來練習四個範例：
1. **斜率 \\(m = \frac{3}{2}\\)，過點 \\(A(1, 5)\\)**：
   分子是 3、分母是 2，上減下寫出 \\(3x - 2y\\)。代入點 \\((1, 5)\\) 得 \\(3(1) - 2(5) = -7\\)，方程式為 \\(3x - 2y = -7\\)。
2. **斜率 \\(m = 3\\)，過點 \\(A(1, 5)\\)**：
   把 3 看成 \\(\frac{3}{1}\\)，上減下寫出 \\(3x - 1y\\)（即 \\(3x - y\\)）。代入點 \\((1, 5)\\) 得 \\(3(1) - 5 = -2\\)，方程式為 \\(3x - y = -2\\)。
3. **斜率 \\(m = -\frac{4}{3}\\)，過點 \\(A(1, 5)\\)**：
   遇到負號，記得把負號給**分母**，看成 \\(\frac{4}{-3}\\)，這樣 \\(x\\) 的首項係數才會是正數。上減下寫出 \\(4x - (-3)y = 4x + 3y\\)。代入點 \\((1, 5)\\) 得 \\(4(1) + 3(5) = 19\\)，方程式為 \\(4x + 3y = 19\\)。
4. **斜率 \\(m = -3\\)，過點 \\(A(1, 5)\\)**：
   把負號給分母，看成 \\(\frac{3}{-1}\\)，上減下寫出 \\(3x - (-1)y = 3x + y\\)。代入點 \\((1, 5)\\) 得 \\(3(1) + 5 = 8\\)，方程式為 \\(3x + y = 8\\)。

反過來看，看到方程式也能秒看斜率：
- \\(3x - 2y = -7\\)：斜率為 \\(\frac{3}{2}\\)（中間是減號，斜率為正）。
- \\(4x + 3y = 19\\)：斜率為 \\(-\frac{4}{3}\\)（中間是加號，斜率為負）。

## 📖 課堂講授：直線幾何關係與練習題實戰

**老師**：我們翻到三之一，繼續演練幾道題目：

1. **斜率 \\(\frac{3}{5}\\)，過點 \\((-4, -3)\\)**：
   上減下得 \\(3x - 5y\\)，代入 \\((-4, -3)\\) 得 \\(3(-4) - 5(-3) = 3\\)，方程式為 \\(3x - 5y = 3\\)。
2. **過點 \\((2, 5)\\) 與 \\((6, -5)\\)**：
   斜率 \\(m = \frac{-5 - 5}{6 - 2} = \frac{-10}{4} = -\frac{5}{2}\\)。負號給分母看作 \\(\frac{5}{-2}\\)，上減下得 \\(5x + 2y\\)。帶入點 \\((2, 5)\\) 得 \\(5(2) + 2(5) = 20\\)，方程式為 \\(5x + 2y = 20\\)。
3. **斜率 \\(-\frac{1}{3}\\)，\\(y\\) 截距為 \\(-3\\)**：
   \\(y\\) 截距表示過點 \\((0, -3)\\)。注意「截距有正有負，截距非距離」。斜率負號給分母看作 \\(\frac{1}{-3}\\)，上減下得 \\(x + 3y\\)，代入 \\((0, -3)\\) 得 \\(-9\\)，方程式為 \\(x + 3y = -9\\)。
4. **\\(x\\) 截距為 \\(-5\\)，\\(y\\) 截距為 \\(-4\\)**：
   兩點為 \\((-5, 0)\\) 與 \\((0, -4)\\)。斜率 \\(m = \frac{-4 - 0}{0 - (-5)} = -\frac{4}{5} = \frac{4}{-5}\\)。上減下得 \\(4x + 5y\\)，代入 \\((-5, 0)\\) 得 \\(-20\\)，方程式為 \\(4x + 5y = -20\\)。
5. **過點 \\((-3, 4)\\)，\\(x\\) 截距為 \\(-1\\)**：
   過點 \\((-1, 0)\\)。斜率 \\(m = \frac{4 - 0}{-3 - (-1)} = \frac{4}{-2} = -2 = \frac{2}{-1}\\)。上減下得 \\(2x + y\\)，代入 \\((-1, 0)\\) 得 \\(-2\\)，方程式為 \\(2x + y = -2\\)。

**【三之二：斜率判斷與圖形對應】**
分析三條直線斜率：第一條斜率為 \\(-5\\)，第二條斜率為 \\(-2\\)，第三條斜率為 \\(1\\)。
只有 \\(L_1\\) 斜率為正，故對應第三個方程式。比較 \\(L_2\\) 與 \\(L_3\\) 的傾斜程度，較傾斜者數字較大，故斜率為 \\(-2\\) 者為 \\(L_2\\)，斜率為 \\(-5\\) 者為 \\(L_3\\)。

**【三之三：平行與垂直線方程式】**
已知過點 \\(A(-3, 2)\\)，與 \\(L: 3x + 2y - 6 = 0\\) 的幾何關係：
1. **平行線**：斜率相等，前項 \\(3x + 2y\\) 保持不變，代入 \\(A(-3, 2)\\) 得 \\(3(-3) + 2(2) = -5\\)，方程式為 \\(3x + 2y = -5\\)。
2. **垂直線**：垂直斜率相乘等於 \\(-1\\)。原斜率為 \\(-\frac{3}{2}\\)，垂直斜率為 \\(\frac{2}{3}\\)。前項係數對調變號得 \\(2x - 3y\\)，代入 \\(A(-3, 2)\\) 得 \\(2(-3) - 3(2) = -12\\)，方程式為 \\(2x - 3y = -12\\)。

**【三之四：平行四邊形題目（大考重點）】**
已知平行四邊形兩鄰邊直線 \\(L_1: 2x + 3y - 6 = 0\\) 與 \\(L_2: x - 3y + 3 = 0\\)，頂點 \\(P(5, 1)\\)。
先檢驗 \\(P(5, 1)\\) 代入 \\(L_1\\) 與 \\(L_2\\) 均不成立，說明 \\(P\\) 點不在這兩條已知邊上，而是對角頂點。
- 與 \\(L_2 (x - 3y)\\) 平行的對邊：\\(x - 3y = 5 - 3(1) \Rightarrow x - 3y = 2\\)。
- 與 \\(L_1 (2x + 3y)\\) 平行的對邊：\\(2x + 3y = 2(5) + 3(1) \Rightarrow 2x + 3y = 13\\)。

## 📖 課堂講授：垂足、對稱點與點到直線距離

**老師**：我們看今天的最後一題：三之五（務必打十顆星，畫三個框框，列為考試必考題）。
已知點 \\(P(-1, 3)\\) 與直線 \\(L: x - y + 2 = 0\\)。求垂足 \\(H\\)、對稱點 \\(P'\\) 與距離 \\(d(P, L)\\)。

1. **求垂足 \\(H\\)**：
   - 直線 \\(L\\) 的斜率為 \\(1\\)。過 \\(P(-1, 3)\\) 且垂直 \\(L\\) 的直線 \\(L_1\\) 斜率為 \\(-1\\)。
   - \\(L_1\\) 方程式：上減下得 \\(x + y\\)，代入 \\(P(-1, 3)\\) 得 \\(x + y = 2\\)。
   - 解聯立方程：
     \\[ \begin{cases} x + y = 2 \\ x - y = -2 \end{cases} \Rightarrow x = 0, y = 2 \\]
     故垂足 \\(H(0, 2)\\)。
2. **求對稱點 \\(P'\\)（變量相等法）**：
   - 從 \\(P(-1, 3)\\) 到 \\(H(0, 2)\\)：\\(x\\) 座標 \\(+1\\)（\\(-1 \to 0\\)），\\(y\\) 座標 \\(-1\\)（\\(3 \to 2\\)）。
   - 對稱點 \\(P'\\) 同樣推移：\\(x\\) 座標再 \\(+1 \Rightarrow 0 + 1 = 1\\)；\\(y\\) 座標再 \\(-1 \Rightarrow 2 - 1 = 1\\)。
   - 故對稱點 \\(P'(1, 1)\\)。（也可以用中點公式：\\(H\\) 為 \\(P\\) 與 \\(P'\\) 的中點）。
3. **求距離 \\(d(P, L)\\)**：
   - 距離即線段 \\(\overline{PH}\\) 的長度：
     \\[ d(P, L) = \sqrt{(0 - (-1))^2 + (2 - 3)^2} = \sqrt{1 + 1} = \sqrt{2} \\]
