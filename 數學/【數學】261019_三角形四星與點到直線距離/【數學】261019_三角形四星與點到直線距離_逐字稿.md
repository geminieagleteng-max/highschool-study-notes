### 一、三角形的四星觀念與推導

**老師**：第一個就是重心。國中的內容基本上到這邊還是差不多的，我們很快速地來看一次。國中有教過的東西，我有承諾過會從頭教，但速度會快一些，所以你要跟上我囉。

重心是三條中線的交點，重心的代號就是 \\(G\\)。有些同學對數學比較敏銳，可能會問我說：為什麼這三條中線剛好會交於同一個點？這個問題蠻有趣的。如果在以前幾何競賽，重心的存在是需要證明的喔！這條中線跟那條中線有一個交點，那為什麼從頂點到交點連起來之後剛好會是中線？這其實是需要討論的，不過我們就先預設，如果你有興趣的話，我們下課再來討論。

重心會有一些蠻有名的特質，第一個性質就是「面積平分性質」。黑板上現在三角形被切割成了六塊，每一塊的面積全部都是一樣的。面積平分性質是所有的重心性質裡面最主要的來源，所以我們來確認一下各位瞭不瞭解這件事情。

所有人抬頭看我，我先問你一下：為什麼這幾塊的面積都會是一樣的？有一個還蠻簡單的觀點：當我今天切了這一刀之後，是不是就會把這個三角形切割成兩塊？當我今天這個地方是往中線切的時候，左邊跟右邊底邊一樣、高也一樣，所以面積一樣。

我們看第二點：
\\[AG : GD = BG : GE = CG : GF = 2 : 1\\]

目前黑板上三個都是國中的內容，國中到這邊就沒有了。我們要看到第三個內容：重心的坐標在高中會出現三次，分別在高一有一次，高二會有兩次。我們看第一次：重心的坐標會是三頂點相加之後除以 3。我們今天上課一開始的目標，就是去證明第三個。那我們先把前面的圈圈一跟圈圈二講清楚吧。

所有人看我，首先 \\(A\\) 往 \\(D\\) 貫穿過去的時候，會在底部形成兩段一樣的底對不對？可是對於左邊的 \\(\Delta ABD\\) 跟右邊的 \\(\Delta ACD\\) 來講，他們的底一樣，而且高度是不是也一樣？所以使得左邊的這個三角形跟右邊的這個三角形兩塊面積是一樣的。

剛剛最上面的頂點是 \\(A\\)，我們把它拉下來變成 \\(G\\)，那麼左邊的 \\(\Delta GBD\\) 跟右邊的 \\(\Delta GCD\\) 的面積是不是也是一樣的？這時候我們把一樣的 \\(\Delta ABD\\) 減掉 \\(\Delta GBD\\)，還有一樣的 \\(\Delta ACD\\) 減掉 \\(\Delta GCD\\)，是不是最後就會讓 \\(\Delta GAB\\) 跟 \\(\Delta GAC\\) 這兩塊殘留的面積一模一樣？如果稍微扭轉一下，就可以證明三塊面積都一樣。三塊都一樣，又被中線一切為二，所以這六塊都是一樣的。大學入學的面試有考過這個簡單的論述喔。

那為什麼圈圈一寫完之後，就會出現圈圈二（\\(2 : 1\\)）呢？
所有人只幫我看左半邊這個 \\(\Delta ABD\\)。把 \\(B\\) 放在最上面，\\(A\\) 跟 \\(D\\) 放在地板上，這時候黑板上的這個三角形切割為三塊，這三塊面積都是一樣的對吧？那這時候我問你：這一塊跟這兩塊是幾比幾？它是 \\(2 : 1\\) 對不對？這兩個三角形的高度是一樣的，高度一樣，面積如果是 \\(2 : 1\\)，那是誰導致的呢？底部對吧？所以這個底部的線段比就會是 \\(2 : 1\\)！

寫好的話，我們要進到高中數學囉。第三點，重心為什麼是三頂點相加之後除以 3 呢？考試最害怕的是它會考證明，我們來討論一下：

第一步： \\(D\\) 點在 \\(B\\) 和 \\(C\\) 的正中間，所以：
\\[D = \frac{B + C}{2}\\]

第二步：\\(G\\) 這個點就是 \\(A\\) 跟 \\(D\\) 的 \\(2 : 1\\) 內分點對吧？內分點公式我們就一起來寫一下：
\\[G = \frac{1 \cdot A + 2 \cdot D}{2 + 1} = \frac{A + 2 \cdot \left(\frac{B + C}{2}\right)}{3} = \frac{A + B + C}{3}\\]

把 \\(D\\) 的坐標帶進來之後，2 跟 2 消掉，分子就剩下 \\(A + B + C\\)，分母是 3。這樣就證明完了！

再來是第二個，高中新的那個心：垂心。垂心是高中才有的，不過垂心的理解上也蠻單純的。隨便幫我畫一個三角形，畫歪歪的比較有感覺。垂心的「垂直」就是垂直的意思，如果今天我從 \\(A\\) 點出發垂直對邊，就會形成一個高。用紅筆幫我畫上三個高，三高的交點就是我們的垂心，代號是 \\(H\\)。

在講大魔王之前，我們再講第三個：外心。
外心的全名是「外接圓的圓心」。你可以先畫一個圓，畫完這個圓再畫三角形。圓是三角形的外接圓，三角形內接在圓的裡面。外接圓的圓心要怎麼用三角形找到呢？

中垂線上有一個非常重要的特質：中垂線上的每一個點到达兩端點的距離相等。倒過來說：到達兩個端點距離相等的點，都會在中垂線上。所以圓心到三角形三個頂點等距（\\(\overline{OA} = \overline{OB} = \overline{OC}\\)），表示圓心必在三邊的中垂線上！三條中垂線的交點就是外心。

第四個：內心。內心全名叫做「內切圓的圓心」。
先幫我畫一個小小的圓，在圓上畫三條切線，這三個切線構成三角形 \\(ABC\\)，圓心就是三角形的內心 \\(I\\)（\\(I\\) 是 internal 內部的意思）。

角平分線上的每一個點，到達角兩邊的距離相等；倒過來說，到兩邊距離相等的點，一定會在角平分線上。因為圓心到三邊的垂直距離都是內切圓半徑 \\(r\\)，所以內心必定是三個角的「角平分線交點」。

接下來是內心的坐標公式，這個非常重要，考試考證明一次就是 10 分！
內心公式：
\\[I = \frac{aA + bB + cC}{a + b + c}\\]
（其中 \\(a, b, c\\) 分別為頂點 \\(A, B, C\\) 的對邊長）

我們來證明這個公式：
在三角形 \\(ABC\\) 中，\\(A\\) 的角平分線交 \\(BC\\) 於 \\(D\\) 點。根據國中角平分線性質，兩側邊長比等於底邊分割比：
\\[\overline{BD} : \overline{DC} = c : b\\]
因此 \\(D\\) 點為 \\(B\\) 與 \\(C\\) 的內分點，由內分點公式：
\\[D = \frac{bB + cC}{b + c}\\]

下一步，我們計算 \\(\overline{BA}\\) 與 \\(\overline{BD}\\) 的真實長度比：
\\(\overline{BA}\\) 的長度為 \\(c\\)；而 \\(\overline{BC}\\) 的總長度為 \\(a\\)，\\(D\\) 點將其分成 \\(b + c\\) 等份，故 \\(\overline{BD} = a \cdot \frac{c}{b + c}\\)。
因此長度比為：
\\[\overline{BA} : \overline{BD} = c : \left(a \cdot \frac{c}{b + c}\right) = (b + c) : a\\]

現在看 \\(\Delta ABD\\)，內心 \\(I\\) 是第二條角平分線的交點，所以 \\(I\\) 點將線段 \\(\overline{AD}\\) 分成的比例也是 \\((b + c) : a\\)！
套用內分點公式求 \\(I\\) 點：
\\[I = \frac{a \cdot A + (b + c) \cdot D}{(b + c) + a} = \frac{aA + (b + c) \cdot \left(\frac{bB + cC}{b + c}\right)}{a + b + c} = \frac{aA + bB + cC}{a + b + c}\\]
\\((b + c)\\) 約分對消，分子精準得到 \\(aA + bB + cC\\)！證明完成！

### 二、範例演練與極值性質

**老師**：請幫我翻到講義 5-1 頁。
第一題非常簡單，已知 \\(A(2, 3)\\), \\(B(5, 4)\\), \\(C(-4, 5)\\)，求重心坐標。
\\(x\\) 坐標：\\(\frac{2 + 5 + (-4)}{3} = 1\\)
\\(y\\) 坐標：\\(\frac{3 + 4 + 5}{3} = 4\\)
所以重心坐標為 \\((1, 4)\\)。

再來看 5-2 頁，這題非常重要！
已知 \\(A(3, 0)\\), \\(B(2, -1)\\), \\(C(-2, 4)\\)，設 \\(P(x, y)\\) 為平面上任意一點，求 \\(PA^2 + PB^2 + PC^2\\) 的最小值。

我們按照定義展開：
\\[PA^2 = (x - 3)^2 + y^2\\]
\\[PB^2 = (x - 2)^2 + (y + 1)^2\\]
\\[PC^2 = (x + 2)^2 + (y - 4)^2\\]
全部展開加起來：
\\[3x^2 + 3y^2 - 6x - 6y + 34\\]

將 \\(x\\) 與 \\(y\\) 各自配方：
\\[3(x^2 - 2x) + 3(y^2 - 2y) + 34 = 3(x - 1)^2 - 3 + 3(y - 1)^2 - 3 + 34 = 3(x - 1)^2 + 3(y - 1)^2 + 28\\]

當 \\(x = 1, y = 1\\) 時，平方項為 0，得到最小值為 28！

這時候看法二（心得）：
大家有沒有發現，\\(x = 1, y = 1\\) 這個點是什麼點？
將 \\(A, B, C\\) 的 \\(x\\) 坐標相加除以 3：\\(\frac{3 + 2 + (-2)}{3} = 1\\)
\\(y\\) 坐標相加除以 3：\\(\frac{0 + (-1) + 4}{3} = 1\\)
這個使距離平方和最小的點，**恰好就是三角形的重心 \\(G\\)**！

請用紅筆背下來：**距離平方和的最小值必定發生在重心！**
背後原理是因為二次函數配方後，頂點剛好落在算術平均數的位置。

翻到 5-3 頁，求垂心。
已知 \\(A(-1, -10)\\), \\(B(2, -1)\\), \\(C(6, -3)\\)，求垂心 \\(H\\)。
垂心是高的交點，兩垂直線斜率相乘等於 \\(-1\\)。
先算底邊 \\(BC\\) 的斜率：
\\[m_{BC} = \frac{-3 - (-1)}{6 - 2} = -\frac{2}{4} = -\frac{1}{2}\\]
因為高與 \\(BC\\) 垂直，所以高 \\(L_1\\) 的斜率為 \\(2\\)。
用斜率寫出直線：\\(2x - y\\)。因為高經過頂點 \\(A(-1, -10)\\)，帶入得：
\\[2(-1) - (-10) = 8 \implies L_1: 2x - y = 8\\]

再算底邊 \\(AC\\) 的斜率：
\\[m_{AC} = \frac{-3 - (-10)}{6 - (-1)} = \frac{7}{7} = 1\\]
與其垂直的高 \\(L_2\\) 斜率為 \\(-1\\)，直線寫成 \\(x + y\\)。經過頂點 \\(B(2, -1)\\)，帶入得：
\\[2 + (-1) = 1 \implies L_2: x + y = 1\\]

解聯立方程：
\\[\begin{cases} 2x - y = 8 \\ x + y = 1 \end{cases}\\]
兩式相加得 \\(3x = 9 \implies x = 3\\)，帶回得 \\(y = -2\\)。故垂心 \\(H(3, -2)\\)。

五之四頁求外心，外心是中垂線交點。作法完全一樣，唯一差別是：中垂線帶入的是「邊的中點」而不是頂點！

### 三、點到直線距離公式與速解技巧

**老師**：請看到第 56 頁「工具九：點到直線距離」。
題目：求點 \\(A(2, 5)\\) 到直線 \\(L: 3x + 4y + 4 = 0\\) 的距離 \\(d(A, L)\\)。

我們先用正規方法做一次：
直線 \\(L\\) 的斜率為 \\(-\frac{3}{4}\\)，故過 \\(A\\) 點且與 \\(L\\) 垂直的直線 \\(L'\\) 斜率為 \\(\frac{4}{3}\\)。
利用上減下寫出垂直線方程式：\\(4x - 3y\\)。帶入 \\(A(2, 5)\\)：
\\[4(2) - 3(5) = -7 \implies L': 4x - 3y = -7\\]

解聯立求垂足 \\(H\\)：
\\[\begin{cases} 3x + 4y = -4 \\ 4x - 3y = -7 \end{cases}\\]
解得垂足 \\(H\left(-\frac{8}{5}, \frac{1}{5}\right)\\)。

計算點 \\(A(2, 5)\\) 到垂足 \\(H\\) 的兩點距離：
\\[d = \sqrt{\left(2 - \left(-\frac{8}{5}\right)\right)^2 + \left(5 - \frac{1}{5}\right)^2} = \sqrt{\left(\frac{18}{5}\right)^2 + \left(\frac{24}{5}\right)^2} = \sqrt{\frac{324 + 576}{25}} = \sqrt{\frac{900}{25}} = \sqrt{36} = 6\\]

正規做法數字很醜又容易算錯，現在傳授兩個快功速解：

**速解一：垂直直線速寫法**
若原直線為 \\(ax + by + c = 0\\)，其垂直線可直接「**係數互換、中間變號**」速寫為：
\\[bx - ay + k = 0\\]

**速解二：點到直線距離公式**
點 \\(P(x_0, y_0)\\) 到直線 \\(ax + by + c = 0\\) 的距離公式：
\\[d = \frac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}\\]

大家跟我唸一次口訣：
> **「根號係數平方和，分之將點帶入取絕對值！」**

我們用公式直接秒殺剛剛的題目 \\(A(2, 5)\\) 到 \\(3x + 4y + 4 = 0\\)：
\\[d = \frac{|3(2) + 4(5) + 4|}{\sqrt{3^2 + 4^2}} = \frac{|6 + 20 + 4|}{5} = \frac{30}{5} = 6\\]
是不是兩秒鐘就出答案了！注意：使用公式時，直線等號右側必須先移項清零！

最後是平行線距離公式：
兩平行線 \\(L_1: ax + by + c_1 = 0\\) 與 \\(L_2: ax + by + c_2 = 0\\) 的距離：
\\[d = \frac{|c_1 - c_2|}{\sqrt{a^2 + b^2}}\\]
口訣：
> **「根號係數平方和，分之長數相減取絕對值！」**

請把公式與口訣補充在講義第 57 頁框框一。今天課程就到這邊，大家休息 15 分鐘！
