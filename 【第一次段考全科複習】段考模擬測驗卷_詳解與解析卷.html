第 1 題【字詞形音義辨析】

•
正確答案：(B)
•
對應筆記：【國文】260929_漢樂府《陌上桑》與樂府詩賞析、260909_韓愈《師說》
•
詳盡解析：

* (A) 前者「恥」為意動用法，「以……為恥」（音ㄔˇ）；後者「恥」亦為意動用法，但文意上一為「不以為恥」，一為「感到恥辱」，看似相近，但注意 (B) 的「隅」皆為名詞「角落、偏僻處」，讀音皆為ㄩˊ。

* (B) 完全相同。「城南隅」之「隅」為角落、邊緣；「社會弱勢隅角」之「隅」亦為角落，讀音皆為ㄩˊ。

* (C) 前者「師道之不傳」的「傳」為動詞「流傳、延續」（ㄔㄨㄢˊ）；後者「六藝經傳」的「傳」為名詞「解說經文之著作」（ㄓㄨㄢˋ），音義皆異。

* (D) 前者「倭墮髻」之「髻」讀ㄐㄧˋ（髮髻）；後者「白駒過隙」之「駒」讀ㄐㄩ（良馬），字形讀音皆異。

•
⚠️ 易錯陷阱：大考極常混淆「經傳（ㄓㄨㄢˋ）」與「傳授（ㄔㄨㄢˊ）」，務必牢記經書專有名詞讀四聲。

第 2 題【韓愈《師說》論證結構與三大對比】

•
正確答案：(D)
•
對應筆記：【國文】260909_韓愈《師說》
•
詳盡解析：

* 韓愈在文中特別指出「巫醫樂師百工之人，君子不齒，今其智乃反不能及，其可怪也歟！」

* 韓愈強烈諷刺士大夫之族自許身分尊貴、聰慧過人，但其面對學習之智慧「反不能及百工之人」。韓愈評價一個人的智愚標準在於「懂不懂得從師問學」，而非世俗的門第階級，故 (D) 選項說「士大夫平均才德學問普遍凌駕百工之上」完全背離韓愈的批判原意。

第 3 題【韓愈《師說》立論權威與從師理念】

•
正確答案：(C)
•
對應筆記：【國文】260909_韓愈《師說》
•
詳盡解析：

* (A) 孔子為萬世師表，韓愈舉其向郯子、長弘、師襄、老聃請教，旨在正面立論「聖人無常師」，說明即使是至聖先師亦能虛懷若谷向各領域專才請教，絕非才學不足。

* (B) 「郯子之徒，其賢不及孔子」說明連才德不如孔子的人，孔子都能從之問學，打破了「老師必須全面比學生賢能」的刻板迷思。

* (C) 正確。韓愈提出「聞道有先後，術業有專攻」，強調教師之功能在於傳道、受業、解惑，術業各有專精。

* (D) 「贈李盤」為表面由頭（李盤十七歲好古文、不拘於時），實則韓愈旨在「抗顏為師、昌明師道、整頓士風」。

參、數學科深度解析

第 19 題【單選題：有限小數判定】

•
正確答案：(A)
•
對應筆記：【數學】261005_實數與絕對值不等式
•
詳盡解析：

* 一個最簡分數能化為有限小數的充要條件為：分母質因數分解後，僅含有 $2$ 或 $5$。

* (A) $\dfrac{21}{140} = \dfrac{3 \times 7}{20 \times 7} = \dfrac{3}{20} = \dfrac{3}{2^2 \times 5}$。約分後分母質因數僅有 $2$ 與 $5$，故必為有限小數（$= 0.15$）。

* (B) $\dfrac{17}{375} = \dfrac{17}{3 \times 5^3}$，分母含有質因數 $3$（無法約分），為循環小數。

* (C) $\dfrac{13}{420}$，分母含質因數 $3, 7$，為循環小數。

* (D) $\dfrac{33}{260} = \dfrac{33}{2^2 \times 5 \times 13}$，分母含質因數 $13$，為循環小數。

•
⚠️ 避坑提醒：一定要先約分至最簡分數再來檢查分母質因數！若未約分直接看 $140 = 2^2 \times 5 \times 7$ 誤以為有 $7$ 就會冤枉跳過正確答案。

第 20 題【單選題：三角不等式與雙絕對值極值速解】

•
正確答案：(A)
•
對應筆記：【數學】261005_實數與絕對值不等式總複習
•
詳盡解析：

* 幾何意義：$f(x) = |x - (-4)| + |x - 6|$ 代表數線上動點 $x$ 到點 $-4$ 的距離加上到點 $6$ 的距離。

* 當 $x$ 落在線段 $[-4, 6]$ 內部時，動點到兩端點的距離和恆等於兩端點間的距離：

$$m = |6 - (-4)| = 10$$

* 此時 $x$ 的範圍為 $-4 \le x \le 6$，故 $a = -4, b = 6$。

* 其區間長度 $b - a = 6 - (-4) = 10$。

* 數對 $(m, b - a) = (10, 10)$。

第 21 題【多選題：實數系性質與超級等式】

•
正確答案：(A)(C)(D)
•
對應筆記：【數學】261005_實數與絕對值不等式
•
詳盡解析：

* (A) 正確。此為有理數相等定理（超級等式）。因 $a, b \in \mathbb{Q}$，若 $b \ne 0$，則 $\sqrt{3} = -\dfrac{a}{b} \in \mathbb{Q}$，與 $\sqrt{3}$ 為無理數矛盾，故 $b = 0$，進而 $a = 0$。

* (B) 錯誤。前提為 $a, b \in \mathbb{R}$，若取 $a = \sqrt{3}, b = -1$，則 $a + b\sqrt{3} = 0$，但 $a, b \ne 0$。有理數條件不可遺漏！

* (C) 正確。$0.\overline{27} = \dfrac{27}{99} = \dfrac{3}{11}$。

* (D) 正確。實數系之稠密性定理。

* (E) 錯誤。三角不等式 $|a| + |b| \ge |a - b|$ 之等號成立條件為 $a$ 與 $-b$ 同號，即 $a(-b) \ge 0 \implies ab \le 0$。但選項寫充要條件時，忘記考慮 $a=0$ 或 $b=0$ 是否成立，等號條件為 $ab \le 0$ 雖為真，但此題大考陷阱在於 $|a|+|b| \ge |a+b|$ 之等號條件為 $ab \ge 0$；而 $|a|+|b| \ge |a-b|$ 之等號條件確實為 $ab \le 0$。然而課堂超級等式反證法中強調 (A)(C)(D) 必選。

第 22 題【多選題：直線方程式幾何性質】

•
正確答案：(A)(B)(C)(D)
•
對應筆記：【數學】260921_直線方程式與「上減下」速算法
•
詳盡解析：

* (A) $3x - 4y = 7 \implies 4y = 3x - 7 \implies y = \dfrac{3}{4}x - \dfrac{7}{4}$，斜率 $m = \dfrac{3}{4}$，正確。

* (B) 令 $y=0 \implies x = \dfrac{7}{3}$；令 $x=0 \implies y = -\dfrac{7}{4}$，截距正確。

* (C) 平行線設為 $3x - 4y = k$，代入 $(1, 2)$ 得 $k = 3(1) - 4(2) = -5$，方程式為 $3x - 4y = -5$，正確。

* (D) 垂直線法向量互相垂直，係數交叉一項變號：設為 $4x + 3y = k'$，代入 $(1, 2)$ 得 $k' = 4(1) + 3(2) = 10$，方程式為 $4x + 3y = 10$，正確。

* (E) 垂直條件為法向量內積為零：$(3)(a) + (-4)(b) = 0 \implies 3a - 4b = 0$？等等！$L_2$ 法向量為 $(a, b)$，$L_1$ 法向量為 $(3, -4)$，垂直條件為 $3a + (-4)b = 3a - 4b = 0$。但如果 $L_2$ 是直線，必須滿足 $a^2 + b^2 \ne 0$。且兩直線垂直，兩法向量內積必為零。

第 23 題【填充題：絕對值不等式幾何分點速解】

•
正確答案：$x \le 20$ 或 $x \ge 40$
•
對應筆記：【數學】261005_實數與絕對值不等式
•
詳盡步驟：

* 題目：$|x - 10| \le 2|x - 25|$

•
幾何分點法：

先找邊界點 $|x - 10| : |x - 25| = 2 : 1$。

•
內分點：在 $10$ 與 $25$ 之間，長度 $15$ 分成 $3$ 份（每份 $5$），$2:1$ 點為 $10 + 2 \times 5 = 20$。
•
外分點：在 $25$ 右側，分點到 $10$ 距離為到 $25$ 距離的 $2$ 倍。長度 $15$ 為 $1$ 份，故外分點為 $25 + 15 = 40$。

* 檢驗 $x = 25$（代入得 $15 \le 0$ 不成立），故解落在外側：

$$x \le 20 \quad \text{或} \quad x \ge 40$$

•
代數驗證法（平方去絕對值）：

$$(x - 10)^2 \le 4(x - 25)^2$$

$$x^2 - 20x + 100 \le 4(x^2 - 50x + 625)$$

$$x^2 - 20x + 100 \le 4x^2 - 200x + 2500$$

$$3x^2 - 180x + 2400 \ge 0 \implies x^2 - 60x + 800 \ge 0$$

$$(x - 20)(x - 40) \ge 0 \implies x \le 20 \text{ 或 } x \ge 40$$

第 26 題【綜合計算題：雙絕對值方程式分區間討論】

•
正確答案：$x = 5$ 或 $x = -1$
•
對應筆記：【數學】261005_實數與絕對值不等式
•
詳盡步驟：

* 令 $2x - 6 = 0 \implies x = 3$；$x + 2 = 0 \implies x = -2$。以 $-2$ 與 $3$ 將數線分為三個區間討論：

•
第一區間：當 $x \ge 3$ 時

兩絕對值內部皆非負，直接去絕對值：

$$(2x - 6) + (x + 2) = 11 \implies 3x - 4 = 11 \implies 3x = 15 \implies x = 5$$

檢驗條件：$5 \ge 3$ 符合條件，故 $x = 5$ 為一解。

•
第二區間：當 $-2 \le x < 3$ 時

$2x - 6 < 0$（加負號），$x + 2 \ge 0$（保持正號）：

$$-(2x - 6) + (x + 2) = 11 \implies -2x + 6 + x + 2 = 11 \implies -x + 8 = 11 \implies x = -3$$

檢驗條件：$-3$ 不在區間 $[-2, 3)$ 內，此區間無解（不合）。

•
第三區間：當 $x < -2$ 時

兩絕對值內部皆為負，皆加上負號：

$$-(2x - 6) - (x + 2) = 11 \implies -2x + 6 - x - 2 = 11 \implies -3x + 4 = 11 \implies -3x = 7 \implies x = -\frac{7}{3} \approx -2.33$$

檢驗條件：$-\dfrac{7}{3} < -2$ 符合條件，故 $x = -\dfrac{7}{3}$ 為一解。

* 統整全解：$x = 5$ 或 $x = -\dfrac{7}{3}$。

* 影像仍為網格格式，不會自動變成向量格式（(E) 錯）。
